# gre

A fast file search and batch rename tool written in Go. 

（This project code is generated by AI, then checked and corrected by human.）

## Features

- **replace**: Fast file content search and replace (inspired by ripgrep)
  - Multi-threaded search and replace
  - Regular expression support
  - Colored output with highlighting
  - Line number display
  - File filtering by glob pattern
  - Binary file detection
  - Dry-run mode for safe preview
  - Intuitive argument parsing (2-argument smart mode)

- **rename**: Batch file renaming tool (inspired by f2)
  - Regular expression matching
  - Capture group replacement ($1, $2, etc.)
  - Dry-run mode (preview before executing)
  - Conflict detection
  - Directory support
  - Force mode for resolving conflicts
  - Case-insensitive file system support

### Key Components

- **pkg/args**: Provides common argument parsing with support for:
  - Simple 2-argument mode (pattern + path or pattern + replacement)
  - Option handling with short and long forms
  - Automatic help generation
  
- **pkg/regex**: Wraps Go's regexp package with:
  - Case-insensitive matching
  - Fixed string support
  - Capture group replacement
  
- **pkg/walker**: Concurrent file system traversal with:
  - Directory skipping (.git, node_modules, etc.)
  - Glob pattern filtering
  - Binary file detection

## Usage

### replace - File Content Search and Replace

```bash
# Basic search
replace "pattern"                    # Search in current directory
replace "pattern" /path/to/dir       # Search in specific directory

# Using explicit options
replace -f "pattern"                 # Explicit find pattern
replace -f "pattern" -r "replace"    # Explicit find and replace
replace -f "TODO" -r "FIXME" -x      # Execute replacement

# Search options
replace -F "pattern"                 # Treat pattern as literal string
replace -g "*.go" "func"             # Search only in Go files
replace -i "pattern"                 # Case insensitive search
replace -j 4 "pattern"               # Use 4 worker threads
replace -n "pattern"                 # Show line numbers (default)
replace -N "pattern"                 # Hide line numbers
replace --no-color "pattern"         # Disable colored output
replace -r "replace"                 # Replacement string
replace -x                           # Execute replacement (default: dry-run)

# Replace (dry-run by default)
replace "TODO" "FIXME"               # Preview replace TODO with FIXME
replace "foo" "bar" -x               # Execute replace

# Examples
replace "TODO" src/                  # Search for TODO in src/
replace -i "error" -g "*.go"         # Case insensitive search in Go files
replace "TODO" src/ test/            # Search in multiple directories
replace "foo" "bar" -x               # Replace all 'foo' with 'bar'
replace -F "[test]" "demo" -x        # Replace literal string '[test]'
```

### rename - Batch File Renaming

```bash
# Basic usage
rename "foo" "bar"                   # Replace 'foo' with 'bar' (dry-run)
rename "foo" "bar" /path/to/dir      # With specific directory

# Using explicit options
rename -f "pattern"                  # Explicit find pattern
rename -f "pattern" -r "replace"     # Explicit find and replace
rename -f "foo" -r "bar" -x          # Execute rename

# Options
rename -d                            # Include directories
rename -F "pattern" "replace"        # Treat pattern as literal string
rename -f "pattern"                  # Pattern to find
rename -g "*.jpg" "pattern" "replace" # Filter by file pattern
rename -i "pattern" "replace"        # Case insensitive matching
rename -r "replace"                  # Replacement string
rename -x                            # Execute (default: dry-run)
rename --force                       # Force rename even with conflicts

# Examples
rename "foo" "bar"                   # Preview: replace 'foo' with 'bar'
rename "foo" "bar" -x                # Execute: replace 'foo' with 'bar'
rename -f "\.txt$" -r ".md" -x       # Change .txt to .md extension
rename -f "(\d+)" -r "prefix_$1" -x  # Add prefix to numbers
rename -i "IMG" "img" -g "*.jpg"     # Case conversion for jpg files
rename -f "^" -r "2024_" -x          # Add date prefix to all files
rename -F "[test]" "demo" -x         # Replace literal string '[test]'
```
